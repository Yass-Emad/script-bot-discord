# سكربت بوت ديسكورد التعليمي | OneDream Bot

## 📋 نظرة عامة
بوت ديسكورد تعليمي متقدم يحتوي على ميزات متعددة لإدارة السيرفرات.

## ✨ الميزات الرئيسية

### 🎵 نظام الموسيقى
- تشغيل الأغاني من يوتيوب
- قائمة انتظار (Queue)
- تكرار الأغاني (Loop)
- التحكم بمستوى الصوت
- لوحة تحكم تفاعلية بالأزرار

### 💾 نظام النسخ الاحتياطي (Vault)
- إنشاء نسخ احتياطية كاملة للسيرفر
- استرجاع النسخ الاحتياطية
- رفع وتحميل النسخ
- تخزين سحابي محلي

### 🛡️ نظام الأمان
- حماية المالك (Owner Protection)
- فريق Ghost Staff السري
- قائمة بيضاء (Whitelist)
- وضع الطوارئ (Emergency Mode)
- سجل تدقيق شامل (Audit Log)

### 📝 التسجيل
- حفظ السجلات في ملفات
- سجل الأحداث (Audit Log)
- سجل الرسائل الخاصة (DM Log)

## 🚀 التشغيل

### المتطلبات
```bash
pip install discord.py yt_dlp
```

### التوكن
1. احصل على توكن البوت من [Discord Developer Portal](https://discord.com/developers/applications)
2. اضبط متغير البيئة `DISCORD_TOKEN` أو عدل التوكن في الكود

### التشغيل
```bash
python "سكربت بوت  ديسكورد اغراض تعليميه.txt"
```

## 🆘 الأوامر الرئيسية

### الموسيقى
- `/music play <اسم الأغنية>` - تشغيل أغنية
- `/music pause` - إيقاف مؤقت
- `/music resume` - استئناف
- `/music skip` - تخطي
- `/music loop` - تكرار
- `/music stop` - إيقاف

### النسخ الاحتياطي
- `/vault` - فتح لوحة النسخ الاحتياطي
- `/upload_backup <ملف>` - رفع نسخة احتياطية

### الإدارة
- `/owner` - لوحة التحكم الرئيسية (في الخاص فقط)
